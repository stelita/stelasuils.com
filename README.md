# stelasuils.com

Stela Suils Cuesta's personal site. Plain HTML and CSS: no builder, no framework, no tracking.

## Files

- `index.html`: all the text and links.
- `style.css`: colours, fonts and layout. The colours at the top (`:root`) follow FairAudit.
- `img/`: photos. Keep each under about 300 KB and no wider than 1400 px.

## How to edit

1. Open `index.html` on github.com (or in any text editor) and click the pencil icon.
2. Change the text between the tags. Keep the tags themselves.
3. Commit the change. GitHub Pages republishes the site within a minute or two.

To swap a photo, upload it to `img/`, then change the file name, the `alt` text (what the photo shows) and the caption in one of the three `<figure>` blocks under "Why me".

## Rules for the content

- Every claim must have a source (see the master CV in Google Docs).
- Keep it short and current: who I help, why me, how to reach me.
- No cookies, analytics or embedded third-party content.
- External links open in a new tab (`target="_blank" rel="noopener"`).
